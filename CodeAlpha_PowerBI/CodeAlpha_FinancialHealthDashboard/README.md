# Financial Health Dashboard – Power BI

## 📊 Project Overview

This project is a **Financial Health Dashboard** created using **Microsoft Power BI** as part of my internship Task 1.

The dashboard transforms financial data into interactive visual reports covering company performance, cash flow, profitability, balance sheet information, and expected quarterly performance.

## 📌 Dashboard Pages

### 1. Financial Overview
Provides a quick overview of:
- Total Sales
- Total Net Profit
- Total Assets
- Total Debt
- Profit Margin
- Sales by Industry
- Net Profit by Industry
- Company/Name slicer for filtering

### 2. Cash Flow Analysis
Includes:
- Operating Cash Flow
- Investing Cash Flow
- Financing Cash Flow
- Net Cash Flow
- Cash Flow Comparison by Company

### 3. Profitability Analysis
Includes:
- Profit Growth
- Sales Growth
- Total Net Profit
- Average OPM
- Sales vs Last Year
- Net Profit vs Last Year

### 4. Balance Sheet Analysis
Includes:
- Total Assets
- Total Debt
- Current Assets
- Current Liabilities
- Average Debt to Equity
- Assets vs Debt comparison

### 5. Financial Forecast
Includes:
- Expected Quarterly Sales
- Expected Operating Profit
- Expected Net Profit
- Expected EPS
- Expected Sales vs Previous Quarter
