# CodeAlpha Power BI Internship Projects

## Human Resources Analytics Dashboard

This project was completed as part of my **CodeAlpha Power BI Internship**.

The objective of this project was to build an interactive Human Resources Analytics dashboard using Power BI to understand employee recruitment, turnover, satisfaction, performance, and hiring requirements.

---

## 📌 Project Overview

The HR Analytics dashboard provides insights into:

- Employee workforce overview
- Recruitment sources
- Hiring trends
- Employee turnover
- Termination reasons
- Employee satisfaction
- Employee performance
- Employee engagement
- Future hiring requirements

The dashboard contains **5 interactive pages**.

---

# 📊 Dashboard Pages

## 1. HR Overview

This page provides an overall view of the workforce.

### Key Metrics

- Total Employees: **311**
- Employees Terminated: **104**
- Attrition Rate: **33.4%**
- Average Employee Satisfaction: **3.89**

### Visualizations

- Employees by Department
- Department selection filter

---

## 2. Recruitment Analysis

This page focuses on employee recruitment and hiring trends.

### Visualizations

- Employees by Recruitment Source
- Employees Hired by Department
- Hiring Trend Over Time

The hiring trend uses monthly hiring data to show how employee hiring changed over time.

---

## 3. Employee Turnover

This page analyzes employee turnover and termination patterns.

### Visualizations

- Employee Turnover by Department
- Termination Reasons
- Employee Turnover by Position

This helps identify departments and positions with higher employee turnover and understand the reasons for termination.

---

## 4. Satisfaction & Performance

This page analyzes employee satisfaction, performance, and engagement.

### Visualizations

- Average Employee Satisfaction by Department
- Average Performance Score by Department
- Employee Performance Distribution
- Employee Engagement vs Satisfaction

The engagement and satisfaction visual helps examine the relationship between employee engagement and satisfaction levels.

---

## 5. Hiring Forecast

This page focuses on historical hiring activity and future hiring requirements.

### Key Metrics

- Total Employees Hired: **311**
- Average Monthly Hiring Need: **5.36**

### Visualizations

- Hiring Trend
- Hiring Forecast

Historical monthly hiring activity was used to create a baseline projection for future hiring requirements.

# 📂 Dataset

The project uses the **HRDataset_v14** Human Resources dataset.

The dataset contains employee-level information such as:

- Employee ID
- Department
- Position
- Salary
- Recruitment Source
- Date of Hire
- Date of Termination
- Employment Status
- Performance Score
- Employee Satisfaction
- Engagement Survey
- Absences
- Termination Reason

---

# 📈 Data Analysis

The project involved:

1. Importing the HR dataset into Power BI.
2. Cleaning and preparing the data using Power Query.
3. Setting appropriate data types for different columns.
4. Creating calculated columns and measures using DAX.
5. Creating interactive charts and KPI cards.
6. Analyzing recruitment and employee turnover.
7. Comparing employee satisfaction and performance.
8. Creating a monthly hiring trend.
9. Creating a baseline projection for future hiring requirements.

---

# 💡 Key Insights

Some of the dashboard insights include:

- The dataset contains **311 employees**.
- **104 employees** are recorded as terminated.
- The overall attrition rate is approximately **33.4%**.
- Employee satisfaction can be compared across different departments.
- Recruitment sources contribute differently to the employee workforce.
- Production has the largest employee count among the departments shown.
- Hiring activity varies across different months and years.
- Historical hiring activity can be used to estimate future hiring requirements.
