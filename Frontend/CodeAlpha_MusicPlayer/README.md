# 🎧 EchoBeat

> **Your Music. Your World.**

EchoBeat is a modern, interactive web-based music player designed to provide an immersive music-listening experience with synchronized lyrics, a rotating vinyl interface, playlists, favorites, search, queue management, and persistent playback preferences.

Built as a project during my **Frontend Development Internship at CodeAlpha**.

---

## ✨ Features

### 💿 Immersive Music Player
- Rotating vinyl record interface
- Current song artwork displayed inside the vinyl
- Smooth play/pause animation
- Song title, artist, album, genre, and year information
- Dedicated bottom music player

### 🎵 Playback Controls
- ▶️ Play / Pause
- ⏮️ Previous Song
- ⏭️ Next Song
- 🔀 Shuffle
- 🔁 Repeat
- 🎚️ Seek through songs
- 🔊 Volume control
- ⏱️ Current time and total duration

### 🎤 Synchronized Lyrics
- LRC-based lyrics support
- Lyrics synchronized with the current playback time
- Active lyric highlighting
- Automatic smooth scrolling
- Click on a lyric to jump to that timestamp
- Dedicated lyrics section below the vinyl player

### 🔍 Search
Search songs using:
- Song title
- Artist
- Album
- Genre

### ❤️ Favorites
- Add songs to Favorites
- Remove songs from Favorites
- Favorite state is saved locally
- Dedicated Liked Songs section

### 📋 Queue
- View the current song queue
- Select any song directly from the queue
- Current song is highlighted

### 💾 Local Storage
EchoBeat remembers important preferences including:
- Last played song
- Volume level
- Shuffle state
- Repeat state
- Favorite songs

### 📱 Responsive Design
Designed to work across:
- 💻 Desktop
- 📱 Mobile
- 🖥️ Different screen sizes
