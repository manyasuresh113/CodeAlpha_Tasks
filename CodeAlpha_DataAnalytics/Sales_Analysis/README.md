# 📊 SuperMarket Sales Analysis

A complete Data Analytics project developed as part of the **CodeAlpha Data Analytics Internship**.

This project analyzes a real-world supermarket sales dataset using **Python, Pandas, Matplotlib, and Seaborn** to uncover business insights, customer behavior, sales trends, and payment preferences.

---

## 📌 Project Objective

The objective of this project is to perform **Exploratory Data Analysis (EDA)** on a supermarket sales dataset and generate meaningful business insights through statistical analysis and visualizations.

## 📊 Dataset Information

- **Dataset:** SuperMarket Sales Dataset
- **Records:** 1000 Transactions
- **Features:** 17 Columns
- **Data Type:** Retail Sales

### Columns

- Invoice ID
- Branch
- City
- Customer Type
- Gender
- Product Line
- Unit Price
- Quantity
- Tax
- Sales
- Date
- Time
- Payment
- Cost of Goods Sold (COGS)

- Rating

## 📌 Key Business Insights

- Identified the highest revenue-generating city.
- Analyzed customer purchasing behavior based on gender.
- Determined the most popular product categories.
- Compared spending patterns of Members and Normal customers.
- Evaluated customer payment preferences.
- Identified peak shopping hours.
- Analyzed customer satisfaction using product ratings.
- Explored relationships among numerical variables using a correlation heatmap.

## ▶️ How to Run

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/SuperMarket-Sales-Analysis.git
```

Navigate into the project

```bash
cd SuperMarket-Sales-Analysis
```

Install dependencies

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook

```bash
jupyter notebook
```

Open

```
notebooks/sales_analysis.ipynb
```

Run all cells.
